# DEC-002 - GitHub não é banco de dados

GitHub guarda código, schemas, SQL, configurações, prompts, testes, documentação e knowledge/. Grandes bases, PDFs históricos e arquivos raw ficam fora do repositório. O banco analítico é o BigQuery; o raw automatizado é preservado no GCS.
